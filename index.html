Masaüstündeki yapay zeka ekibin

Maillerini okuyup özetleyen, internette araştıran, dosyalarını düzenleyen, işleri zamanında yapan ve bilgisayarını senin yerine kullanan bir ekip. Sen sadece söyle.

Kendi Anthropic API anahtarınla çalışır. Ayarların ve şifrelerin sadece senin bilgisayarında saklanır.

Bir ekip, tek sohbet penceresi

Her çalışanın bir görevi ve yetkisi var. İstediğin kadar yeni çalışan ekleyebilir, görevlerini değiştirebilirsin.

Mail asistanı

Gmail'ini okur, özetler, taslak yazar, istersen gönderir. Beklediğin kişiden mail gelince anında haber verir.

Araştırmacı

İnternette arar, sayfaları okur, kaynaklı kısa özetler çıkarır: haberler, kurlar, hava durumu.

Dosya düzenleme

İzin verdiğin klasörleri türlerine göre düzenler, dosya bulur. Dosya silmez.

Bilgisayar kontrolü

Ekrana bakıp uygulama açar, tıklar, yazar; WhatsApp'tan mesaj gönderir. Önemli adımlarda önce sana sorar.

Zamanlanmış işler

"Her sabah 8'de maillerimi özetle" de, zamanı gelince kendiliğinden yapsın.

Müdür ve ekip toplantısı

Müdür işi bölüp ekibe dağıtır. "Ekip" sohbetinde herkes sırayla cevap verir.

Hareketli sanal ofis

Ekibin bir ofiste oturur: çalışan yazıyor, ekranı açılıyor, molada kahve içiyor. Kim ne yapıyor tek bakışta görürsün.

Toplantı ve brifing

"Toplantı yap" de, seçtiğin çalışanlar toplantı odasına geçsin; herkes günün raporunu versin, Müdür yapılacakları çıkarsın.

Büyüyen ofis

Yeni oda ekle (çalışma, toplantı, dinlenme), odaları adlandır, çalışanları taşı. Her yeni çalışana masa kendiliğinden açılır.

İndir ve kur

DeskCrewAI-Setup.exe'yi aç, "İleri"ye bas. Yönetici izni gerekmez. Windows uyarı verirse "Ek bilgi → Yine de çalıştır".

API anahtarını ekle

Ayarlar'a Anthropic API anahtarını yapıştır. console.anthropic.com

Gmail'i bağla (isteğe bağlı)

Gmail adresini ve uygulama şifresini gir. myaccount.google.com/apppasswords

Sık sorulan sorular

Ücretli mi?

Program ücretsiz. Yapay zeka için kendi Anthropic API anahtarını kullanırsın, kullandığın kadar Anthropic'e ödersin. Normal günlük kullanım genelde birkaç dolar tutar.

Bilgilerim güvende mi?

API anahtarın ve Gmail şifren Windows Kimlik Bilgisi Yöneticisi'nde, sadece senin bilgisayarında saklanır. Mailler yalnızca sen istediğinde gönderilir; asistan dosya silmez.

Windows "bilinmeyen yayıncı" uyarısı veriyor

Program henüz dijital olarak imzalı olmadığı için SmartScreen bu uyarıyı gösterir. "Ek bilgi"ye tıklayıp "Yine de çalıştır" diyebilirsin.

Mac sürümü ne zaman?

Üzerinde çalışıyoruz. Şimdilik Windows 10 ve 11 destekleniyor.

Nasıl kaldırırım?

Ayarlar → Uygulamalar'dan "DeskCrew AI"ı kaldır. Tekrar kurarsan ayarların geri gelir.
